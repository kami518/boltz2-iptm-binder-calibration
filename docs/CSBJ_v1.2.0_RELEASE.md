# CSBJ v1.2.0 release

This release accompanies the CSBJ Research Article *Target-held-out
calibration and conditional experimental value of Boltz-2 ipTM in binder
design*.

The complete `v1.2.0` reproducibility archive is attached to the GitHub
release and archived on Zenodo at `10.5281/zenodo.24561385`. It contains:

- final figure-free manuscript, landscape tables, and Supporting Information
  in DOCX and PDF;
- Figures 1-8 and Supplementary Figures S1-S13 in PDF and SVG with 600-dpi PNG
  previews;
- the accepted target-as-new run configuration, outputs, QC, and hash manifest;
- 30 panel-level traceability records;
- the exact plotted CSV source and run manifest for every traced panel;
- figure generation, manuscript build, and final verification scripts.

The earlier `v1.1.0` release and DOI `10.5281/zenodo.24400262` remain unchanged.
No raw third-party model weights, structure inputs, or restricted vendor data
are redistributed.
