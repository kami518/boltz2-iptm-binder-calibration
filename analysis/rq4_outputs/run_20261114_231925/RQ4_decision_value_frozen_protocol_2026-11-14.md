## 1. 研究问题与解释边界

RQ4 回答：在固定湿实验预算下，使用 Boltz-2 ipTM 或本地标签适配后的概率，实际能选出多少真 binder，以及固定阈值和跨靶点资源分配会产生什么后果。

RQ4 不再检验“ipTM 是否为概率”，也不重新选择 RQ3 的校准模型。所有结论只适用于当前已筛选并进入实验的候选库。RQ4-C 是多个靶点同时竞争共享预算的回顾性模拟，不是前瞻性部署证据，不提供对未来靶点总体分布的推断。

全文使用“靶点及其绑定的 campaign／assay／source 上下文”，不把统计差异直接归因于靶点生物学本身。

## 3. 通用指标与区间

每个选择集合报告：

- 实际实验数 `n_selected`；
- 真阳性数 `hits`；
- `precision = hits / n_selected`；
- `recall = hits / 当前候选库全部阳性数`；
- `enrichment = precision / 当前候选库阳性率`；
- 同预算随机选择的期望命中数 `n_selected × 当前候选库阳性率`；
- 相对随机的命中增益 `hits − 期望命中数`；
- 每个 hit 的实验成本 `n_selected / hits`；零命中时记为不可定义，不改写为 0。

空选集合保留：`n_selected=0`，hits=0，precision／recall／enrichment／单位成本记为不可评价，并说明分母。

RQ4-A／B 在每个靶点内按 `sequence_cluster90` 整簇有放回重采样 2,000 次，随机种子 20261115；每次重新执行相同选择规则并重算指标。报告 percentile 95% 区间。该区间是当前靶点和候选库内的条件不确定性，不是未来靶点覆盖区间。

## 4. RQ4-A：逐靶点固定预算——主要决策分析

### 4.1 预设预算

1. 比例预算：每靶点原始 ipTM 前 5%、10%、20%；`k=ceil(n_target×fraction)`。
2. 绝对预算：`k=10、20、50`。这是看到 RQ3／RQ3-E 后新增的**探索性敏感性**，不回填为原确认性设定。

按 ipTM 降序选择；如 cutoff 出现并列，为保持固定 k，以 `pair_id` 升序作确定性 tie-break，并单独报告 cutoff 并列。脚本必须复核各靶点 ipTM 重复值及 cutoff 并列。

### 4.2 报告方式

逐靶点报告第 3 节全部指标和区间；另报告六靶点合计实验数／命中数、靶点等权宏平均及五靶点对照。不得把 AAH-I 的高区分能力隐藏在 pooled 总命中中。

单调 U／I／F 不改变同一靶点内的 ipTM 排序，因此 RQ4-A 只评价原始 ipTM 的筛选价值，不声称再校准提高靶点内 top-k 命中率。

## 5. RQ4-B：原始 ipTM 固定 operating points

固定阈值为 **0.80、0.90、0.95**，选择 `boltz2_iptm ≥ threshold`。

逐靶点报告第 3 节指标和区间。阈值只称为“原始 ipTM operating points”，不得称为 80%／90%／95% 成功概率阈值。允许并保留空选集合；不搜索最佳阈值，不把不同靶点合并后推荐一个通用截点。

## 6. RQ4-C：跨靶点共享预算与 pilot 成本——探索性模拟

### 6.1 折外 U 的角色与排序边界

每个留出靶点使用其对应的 RQ3 LOTO `eta_U`；该 U 只由其他源靶点训练。主分析使用 `primary_six / sequence_cluster90 / target_equal / linear`；五靶点和严格结局使用各自对应的冻结折外 U，不重训全数据模型。

每个靶点的 U 都是该靶点原始 ipTM 的严格单调变换，因此二者在**靶点内**完全同序。不同留出靶点使用不同 LOTO 源模型，跨靶点合并后不保证同序；这些预测不能被解释为同一个统一部署映射。

RQ4-C 不另设“U 共享排序”策略。唯一零标签排序基线为原始 ipTM；折外 U 只作为 pilot-I／F 的适配起点，用于交叉验证式评价“源模型＋本地 pilot”的流程，而非评价一个固定的全六靶点部署模型。

### 6.2 共享预算与 pilot 网格

- 总预算：`B=120、300` 个湿实验。
- 每靶点 pilot 数：`m=10、20、40`。
- 仅执行 `靶点数×m ≤ B` 的组合；允许 pilot 用尽预算，此时后续筛选数为 0。
- 所有策略在同一分析集内使用相同 B；pilot 消耗从 B 中扣除。
- **pilot 中发现的阳性计入总 hits**；pilot 已测配对不得再次入选或重复计数。

这些网格全部预先列出并完整报告，不根据结果选择最有利的 B 或 m。

### 6.3 比较策略

1. `raw_ipTM`：不用 pilot，全部候选按原始 ipTM 降序选前 B。
2. `equal_budget_ipTM`：不用 pilot，每靶点等额分配 B，并在各靶点内按 ipTM 排序；本协议的 B 均可被 6 或 5 整除。
3. `random_allocation`：不用 pilot，从全部候选中无放回随机选择 B 个配对。
4. `pilot_I`：每靶点先做 m 个 pilot，只更新截距，再在剩余候选中按预测概率分配 `B−靶点数×m` 个后续实验。
5. `pilot_F`：相同 pilot，同时更新截距和斜率，再分配相同后续预算。

### 6.4 序列簇 pilot 抽样

每轮、每靶点：

1. 随机排列该靶点的 `sequence_cluster90` 簇；
2. 取前 m 个簇，每簇随机抽取一个配对作为 pilot；
3. 为防止 pilot 与后续评价出现同簇近重复，已选簇的全部配对从后续候选池移除；未测的簇成员不计实验数，也不计 hits；
4. 若可用簇不足 m，则该组合记为不可评价，不减少 m 或改用其他抽样。

这是预先固定的“簇代表 pilot＋后续去同簇”策略。它可能丢弃未测候选，是策略本身的成本；结果不得外推为所有可能 pilot 设计的最优解。

### 6.5 小 pilot 的 I／F 数值规则

RQ4-C 不是重新执行 RQ3 的大训练折 CV。为使 m 很小、甚至单类 pilot 仍有有限参数，预先固定以下探索性规则：

- 令 `eta_U` 为对应 RQ3 折外 U 的 logit 预测；pilot 阳性数为 h。
- 基率采用 Jeffreys 平滑：`p_tilde=(h+0.5)/(m+1)`。
- I：求截距更新 a，使 pilot 上 `mean(expit(a+eta_U))=p_tilde`；斜率保持不变。
- F：令 `eta_F=a+(1+delta)×eta_U`。对每个 delta，求 a 使 pilot 平均预测等于同一个 `p_tilde`；选择最小化 `mean(NLL)+0.5×lambda×delta²` 的 delta。
- 固定 `lambda=0.1`；不使用后续候选或外测标签选择 lambda，不根据结果改网格。
- 允许 F 得到负总斜率；原样记录，不作事后符号修补。
- 后续筛选只使用预测概率排序；所有剩余候选的真实标签只用于最终评价。

该平滑与固定 ridge 是小 pilot 决策模拟的方法性简化，必须与 RQ3 的预测性 I／F 区分，不能宣称复现或替代 RQ3 模型。

### 6.6 重复、汇总与公平性核查

- 主结局六靶点：2,000 次模拟；五靶点与严格结局：各 1,000 次。
- 随机种子 20261114；同一分析集、m 和重复的 pilot 在不同可行 B 间复用。
- 每次模拟保存各策略总实验数、pilot 数、后续数、pilot hits、后续 hits、总 hits、precision、单位成本，以及逐靶点后续分配数。
- 汇总均值、标准差、2.5%／97.5% 模拟分位数；对 I−raw、F−raw、F−I 等逐轮命中差给出区间和 `P(差值>0)`。
- 这些是候选库与抽样机制条件下的模拟分布，不是未来 campaign 的置信区间。

必须自动核查：总实验数恒等于 B；pilot hits＋后续 hits＝总 hits；同一配对不重复计数；raw 与 U 在每个靶点内排序完全相同；不把不同 LOTO 的 U 当作一个统一部署映射；pilot 成本没有被免除。
