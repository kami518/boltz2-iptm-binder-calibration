## 4. 预设对照与验收

绝对预算 k=10／20／50、排除 AAH-I、严格结局、Miniprotein-only，以及 RQ4-C 的五靶点和严格结局结果均保存在 CSV 中。解释时须区分原预设比例预算与后增绝对预算，且不得将模拟分位数称为未来靶点的置信区间。

RQ4-C 的关键对照为：

- B=300、m=10 时，I−raw 的平均命中差在主六靶点、五靶点和严格六靶点中分别为 **+18.08、+19.87、+22.66**，方向一致。
- B=120、m=10 时，相应差值为 **−3.39、+2.64、+1.45**，方向不一致；不能宣称小预算下 pilot 有稳定收益。
- B=300、m=20 时，相应差值为 **−0.81、+9.36、+8.25**，主六靶点与两个对照不同；m=40 时三类分析均为明显负差。
- F−I 的平均命中差在各可行组合中均未显示稳定的额外收益。该模拟不支持用更多 pilot 或额外斜率适配作为通用建议。

独立验收已完成 **23／23 项检查**：包括全部 207 个 A／B 点估计规则、4 个 bootstrap 区间复核、全部 C 汇总和配对差值、三套分析首轮 30 个策略结果的独立回放、图像完整性及最终文件哈希。验收目录为 `analysis/audit_outputs/RQ4_acceptance_run_20261114_231925`。

结论仍是条件性的：小 pilot 在部分较大共享预算情景中有价值，但不能仅凭某一 B／m 组合宣布 pilot 或 F 普遍有效。
